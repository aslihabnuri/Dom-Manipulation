# Kasus AirAsia: The World's Lowest Cost Airline

Materi presentasi Kelompok 3 untuk Strategic Management (MAN 5422), sesi 4: Evaluating a Company's External Environment.

Berkas:

- `SMJKT_Group 3_Aslih_Case AirAsia.pptx`: deck 20 slide dengan latar lukisan kolase, font isi 24 pt, dapat diedit di PowerPoint.
- `SMJKT_Group 3_Aslih_Case AirAsia.pdf`: versi PDF dari deck yang sama.
- `build_deck.js`: skrip pptxgenjs yang menghasilkan deck dari gambar di folder `img/`. Jalankan `npm install pptxgenjs` lalu `node build_deck.js "nama_file.pptx"`.
- `gen_images.py`: skrip pembuat gambar latar lewat API kie.ai (model google/nano-banana, 4 kredit per gambar). Butuh variabel lingkungan `KIE_KEY`; kunci tidak disimpan di repo.
- `img/`: 28 gambar latar hasil generasi, format JPEG.

Seluruh angka bersumber dari Tabel 9.1 sampai 9.5 kasus Grant (2010). Nama berkas mengikuti format RPKPS.
