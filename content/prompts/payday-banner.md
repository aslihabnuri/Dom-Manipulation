# Prompt banner Payday — opsi 4 dan opsi 5

Dua prompt siap salin. Isinya sama persis kecuali headline, jadi hasilnya bisa diadu langsung.

**Sebelum dikirim:** ganti `[XX]`, `[25 – 31]`, dan `[OCTOBER]`. Prompt sudah berisi pengaman: kalau masih ada kurung siku, model diminta bertanya, bukan mencetaknya.

## Yang saya ubah dari bagian prompt Anda

1. **Urutan produk.** Kalimatnya "Boxer Brief dan Kaos Dalam", tapi link pertama adalah singlet putih (`TNB 5 gm.jpg`) dan link kedua boxer brief hitam (`6a.png`). Urutan katanya saya samakan dengan urutan link dan saya beri warna, supaya model tidak menukar keduanya. Ditambah "dikenakan oleh model" supaya produknya dipakai, bukan ditempel sebagai foto produk.
2. **Logo.** `6.png` itu logo putih di atas kotak abu gelap padat, tanpa transparansi; 98 % pikselnya gelap. Di latar terang seperti referensi, hasilnya akan jadi kotak gelap menempel di atas. Saya tambahkan instruksi untuk menampilkannya hitam tanpa kotak.
